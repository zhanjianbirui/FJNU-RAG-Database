## MODIFIED Requirements

### Requirement: 配置驱动的爬取

爬取行为 SHALL 完全由站点配置与结构库中被勾选的范围共同决定：站点配置提供 URL 准入与排除规则、分页规则与各模板的字段抽取选择器，结构库提供待爬取的栏目与页面模板。接入一个新站点 MUST NOT 需要修改代码。爬取 MUST NOT 越出被勾选的范围。

#### Scenario: 按配置爬取一个新站点
- **WHEN** 用户提供一份合法的新站点配置与一份已勾选范围的结构库并启动爬取
- **THEN** 系统在不修改任何代码的前提下完成该站点的爬取

#### Scenario: 配置非法
- **WHEN** 站点配置缺少必填字段或字段类型错误
- **THEN** 系统在发起任何网络请求之前中止，并报告具体的字段路径与错误原因

#### Scenario: 未勾选任何范围
- **WHEN** 结构库中没有任何被勾选的栏目或模板
- **THEN** 系统在发起任何网络请求之前中止，并提示需先选择爬取范围

#### Scenario: URL 超出勾选范围
- **WHEN** 页面中发现的链接属于未被勾选的栏目
- **THEN** 系统不抓取该链接

#### Scenario: URL 超出准入范围
- **WHEN** 页面中发现的链接不匹配配置的准入规则，或匹配排除规则
- **THEN** 系统不抓取该链接

#### Scenario: 结构库已过期
- **WHEN** 待爬取的结构版本已不是生效版本
- **THEN** 系统提示结构已更新并要求确认，而非按过期结构继续爬取
