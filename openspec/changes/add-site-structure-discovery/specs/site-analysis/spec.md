## MODIFIED Requirements

### Requirement: 站点采样

系统 SHALL 在遵守目标站点 `robots.txt` 与速率限制的前提下采样页面，用于抽取规则的推断。采样单位 SHALL 是页面模板而非栏目：多个栏目共用同一模板时，系统 MUST 只为该模板采样一次。采样规模 MUST 可配置，并 MUST 有默认上限以避免对目标站点造成压力。

#### Scenario: 按模板采样详情页
- **WHEN** 结构探测已识别出某页面模板及其样本 URL
- **THEN** 系统采样不超过配置上限的该模板页面
- **AND** 返回采样到的页面数量与各页面的 URL

#### Scenario: 共用模板的栏目不重复采样
- **WHEN** 多个栏目被判定为同一页面模板
- **THEN** 系统只为该模板采样一次，不对每个栏目分别采样

#### Scenario: robots.txt 禁止采样
- **WHEN** 待采样 URL 被该站点 `robots.txt` 禁止抓取
- **THEN** 系统拒绝采样该 URL，不发起请求，并向用户报告被禁止的 URL 与对应的 robots 规则

#### Scenario: 样本页无法访问
- **WHEN** 样本 URL 返回 4xx/5xx 或连接超时
- **THEN** 系统报告该 URL 失败及其状态码或错误原因，并继续处理其余样本，而非整体中止

### Requirement: 结构推断与选择器建议

系统 SHALL 在使用者确认爬取范围**之后**，为每个被选中的页面模板分别推断抽取规则，为正文区域、标题、发布日期、发布部门、附件链接输出候选 CSS 选择器，每个候选 MUST 附带在该模板样本中的命中率。系统 MUST NOT 在结构探测阶段推断选择器，也 MUST NOT 为未被选中的模板推断选择器。

#### Scenario: 输出带命中率的候选选择器
- **WHEN** 对某个被选中模板的多个页面样本完成结构推断
- **THEN** 每个字段返回按命中率降序排列的候选选择器列表
- **AND** 每个候选标明它在多少个样本页面上成功抽取到非空内容

#### Scenario: 命中按真实抽取路径判定
- **WHEN** 某候选选择器在页面上匹配到多个元素
- **THEN** 命中与否以实际抽取时取用的那个元素为准，而非以页面上存在任一满足条件的元素为准

#### Scenario: 每个模板独立成套
- **WHEN** 一个站点被选中两个结构不同的页面模板
- **THEN** 系统为两个模板分别输出各自的选择器集合，而非合并为整站一套

#### Scenario: 某字段无可用候选
- **WHEN** 某字段（如发布部门）在所有样本中都无法定位
- **THEN** 系统为该字段返回空候选列表并标记为"需人工指定"，而非返回一个命中率为零的选择器

#### Scenario: 未选中的模板不被推断
- **WHEN** 结构库中存在未被勾选的页面模板
- **THEN** 系统不为其推断选择器，也不为其发起任何页面请求

### Requirement: 站点配置草稿生成

系统 SHALL 将推断结果输出为站点配置草稿，其格式 MUST 与爬虫实际消费的配置格式一致，使其可被直接编辑后投入使用。草稿 SHALL 按被选中的范围生成，每个被选中的页面模板对应一组抽取规则。

#### Scenario: 生成可用的配置草稿
- **WHEN** 对被选中范围完成结构推断
- **THEN** 系统写出一份站点配置草稿文件，其中每个字段填入命中率最高的候选选择器
- **AND** 该草稿通过爬虫配置的格式校验

#### Scenario: 草稿覆盖被选中的模板
- **WHEN** 使用者选中了两个页面模板
- **THEN** 草稿中包含两组抽取规则，并标明各自对应的模板与所覆盖的栏目

#### Scenario: 草稿中标注低置信度字段
- **WHEN** 某字段最高候选的命中率低于配置的置信度阈值
- **THEN** 草稿中该字段旁 MUST 带有提示注释，说明命中率偏低需人工确认
