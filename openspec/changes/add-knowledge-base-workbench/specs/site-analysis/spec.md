## Purpose

在把一个网站纳入知识库前，自动采样其页面结构，推断出正文、标题、发布时间与附件链接的抽取规则，并产出可直接编辑使用的站点配置草稿，使接入工作从编写代码降级为修改配置。

## ADDED Requirements

### Requirement: 站点采样

系统 SHALL 接受一个或多个入口 URL，在遵守目标站点 `robots.txt` 与速率限制的前提下采样页面，用于结构推断。采样规模 MUST 可配置，并 MUST 有默认上限以避免对目标站点造成压力。

#### Scenario: 从入口页采样列表页与详情页
- **WHEN** 用户提供一个列表型栏目（如通知公告）的入口 URL
- **THEN** 系统抓取该入口页，识别出指向详情页的链接，并采样不超过配置上限的详情页样本
- **AND** 返回采样到的页面数量与各页面的 URL

#### Scenario: robots.txt 禁止采样
- **WHEN** 目标入口 URL 被该站点 `robots.txt` 禁止抓取
- **THEN** 系统拒绝采样该 URL，不发起请求，并向用户报告被禁止的 URL 与对应的 robots 规则

#### Scenario: 入口页无法访问
- **WHEN** 入口 URL 返回 4xx/5xx 或连接超时
- **THEN** 系统报告该入口失败及其状态码或错误原因，并继续处理其余入口，而非整体中止

### Requirement: 结构推断与选择器建议

系统 SHALL 基于采样到的页面，为正文区域、标题、发布日期、发布部门、附件链接分别输出候选 CSS 选择器，每个候选 MUST 附带在样本中的命中率。

#### Scenario: 输出带命中率的候选选择器
- **WHEN** 对同一栏目的多个详情页样本完成结构推断
- **THEN** 每个字段返回按命中率降序排列的候选选择器列表
- **AND** 每个候选标明它在多少个样本页面上成功抽取到非空内容

#### Scenario: 某字段无可用候选
- **WHEN** 某字段（如发布部门）在所有样本中都无法定位
- **THEN** 系统为该字段返回空候选列表并标记为"需人工指定"，而非返回一个命中率为零的选择器

### Requirement: 站点配置草稿生成

系统 SHALL 将推断结果输出为一份站点配置文件草稿，其格式 MUST 与爬虫实际消费的配置格式一致，使其可被直接编辑后投入使用。

#### Scenario: 生成可用的配置草稿
- **WHEN** 结构推断完成
- **THEN** 系统写出一份站点配置草稿文件，其中每个字段填入命中率最高的候选选择器
- **AND** 该草稿通过爬虫配置的格式校验

#### Scenario: 草稿中标注低置信度字段
- **WHEN** 某字段最高候选的命中率低于配置的置信度阈值
- **THEN** 草稿中该字段旁 MUST 带有提示注释，说明命中率偏低需人工确认

### Requirement: 不覆盖既有配置

系统 MUST NOT 静默覆盖已存在的站点配置文件。

#### Scenario: 目标配置文件已存在
- **WHEN** 用户对一个已有配置的站点重新运行站点分析
- **THEN** 系统将草稿写入一个新的、不冲突的文件路径，并告知用户该路径与原配置路径
